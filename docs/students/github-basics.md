## What Is GitHub?

**GitHub** is a website where people store, share, and collaborate on code and other files. Think of it as Google Drive — but designed specifically for building software together.

It's used by over 100 million developers worldwide, from school students to professional engineers at companies like Microsoft, Google, and NASA.

You don't need to know how to code to use GitHub. Many people use it for:
- Writing documents and notes (like this website!)
- Tracking tasks and project ideas
- Sharing creative writing or portfolios
- Collaborating on almost any kind of project

## Part 1 — Key Concepts

Before we jump in, here are a few important words you'll encounter:

| Term | What It Means |
|------|---------------|
| **Repository (repo)** | A folder/project on GitHub that contains all your files |
| **Commit** | Saving a version of your file with a description of what changed |
| **Branch** | A separate copy of your project where you can make changes safely |
| **Pull Request (PR)** | A request to add changes from one branch into another |
| **README** | A special file that explains what a project is about |
| **Fork** | Making your own copy of someone else's repository |
| **Clone** | Downloading a repository to your own computer |

Don't worry about memorising all of these right now. You'll pick them up as you go.

## Part 2 — Create Your GitHub Account

Let's get you set up! 🎉

### Step 1: Go to GitHub

1. Open a new browser tab
2. Go to [github.com](https://github.com)
3. Click **"Sign up"** (top right)

### Step 2: Create Your Account

1. Enter an email address
2. Choose a password
3. Choose a username — this will be your GitHub identity, so pick something you like!
4. Complete the verification steps
5. Check your email and verify your address

!!! tip "Choosing a username"

    Pick something professional — you might share this with future employers or collaborators. Your name, a nickname, or something related to your interests all work well.

### Step 3: Complete the Setup

GitHub will ask you a few questions. You can:
- Select the free plan (it's perfectly fine for what we're doing)
- Skip optional steps if you prefer

**Congratulations — you now have a GitHub account!** 🎊

## Part 3 — Create Your First Repository

A repository is a project folder. Let's create one.

### Step by Step

1. When signed in, click the **"+"** button in the top right corner
2. Select **"New repository"**
3. Fill in the details:
   - **Repository name**: `my-first-repo` (or anything you like!)
   - **Description**: "My first GitHub repository" (optional but helpful)
   - **Public or Private**: Choose **Public** for now (others can see it) or **Private** (only you can see it)
   - ✅ Tick the box: **"Add a README file"**
4. Click the green **"Create repository"** button

You've just created your first repository! 🎉

## Part 4 — Edit Your README

A README is a document that explains what your project is about. Let's edit it.

### Step by Step

1. In your new repository, you'll see a file called `README.md`
2. Click on it to open it
3. Click the **pencil icon** ✏️ on the right side to edit it
4. Replace the existing text with something about yourself, like:

   ```markdown
   # My First Repository

   Hi! I'm learning to use GitHub. This is my first repository.

   ## About Me
   - I'm interested in AI and technology
   - I'm learning through Workshop Hub
   - I'm based in [your city]

   ## What I'm Learning
   - How to use GitHub
   - Basics of AI
   - Product development thinking
   ```

5. Scroll down to the **"Commit changes"** section
6. Add a message like: *"Update README with intro"*
7. Click **"Commit changes"**

!!! tip "What does 'commit' mean?"

    Committing saves a snapshot of your file with a description of what changed. It's like hitting save — but better, because you can always go back to any previous version.

## Part 5 — Understanding Version Control

This is the big idea behind GitHub. **Version control** means tracking every change ever made to your files, so you can:

- See what changed, when, and who changed it
- Go back to an older version if something breaks
- Work on changes without affecting the main version
- Collaborate with others without overwriting each other's work

### Seeing Your History

1. In your repository, click on **"Commits"** (usually near the top of the file list)
2. You'll see a list of every save you've made
3. Click on a commit to see exactly what changed

This is incredibly powerful when working on bigger projects. If something breaks, you can instantly see what changed and when.

## Part 6 — Explore GitHub

Now that you have an account and a repository, let's explore:

### Things to Try

- **Search for interesting projects**: Use the search bar at the top to look for topics you like (e.g. "beginner Python", "climate data", "games")
- **Star a repository**: If you find something interesting, click the ⭐ Star button — it saves it to your profile
- **Look at a README**: Browse any popular repository and read its README to understand what the project does
- **Follow someone**: You can follow other GitHub users to see what they're working on

## Key Takeaways

- GitHub is a place to store, share, and collaborate on files and code
- A repository is a project folder; a commit is a saved version with a description
- Version control means you can always go back to any previous version
- You don't need to code to use GitHub — anyone can use it for any kind of project
- You now have a real GitHub account and your first repository 🎉
