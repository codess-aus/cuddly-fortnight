## Who Is This For?

These workshops are for you if you:

- [x] Have little or no experience with technology or coding
- [x] Have heard about AI and want to understand what it actually is
- [x] Want to start building things, not just reading about them
- [x] Are curious about careers in technology or product development
- [x] Want to understand GitHub and why developers use it

!!! tip "Start at the beginning"

    We recommend doing the workshops in order — each one builds a little on the previous one. But if you're curious about a specific topic, feel free to jump straight in.

---

## Before You Begin

Here's what you'll need:

- A **computer, tablet, or phone** with an internet connection
- A **free GitHub account** — you'll create one in Workshop 2 if you don't have one
- **Curiosity and patience** — that's it 😊

The workshops are designed to be done on your own or with friends. Each one takes about **60–90 minutes**.
