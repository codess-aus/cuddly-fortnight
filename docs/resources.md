## Useful Definitions

!!! tip "Glossary of key terms"

    **AI (Artificial Intelligence)** — Software that learns from examples to make predictions or decisions.
    
    **Machine Learning** — A type of AI that learns patterns from data.
    
    **Generative AI** — AI that creates new content: text, images, code, audio.
    
    **GitHub** — A platform for storing, sharing, and collaborating on code and other files.
    
    **Repository (repo)** — A project folder on GitHub.
    
    **Version control** — Tracking every change to files over time.
    
    **Agile** — A way of building products in short, iterative cycles.
    
    **User persona** — A fictional character representing a type of real user.
    
    **Design thinking** — A problem-solving approach focused on understanding users.
    
    **Bias (in AI)** — When an AI system produces unfair outcomes for certain groups.
    
    **Hallucination** — When an AI produces confident-sounding but incorrect information.
