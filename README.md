# Workshop Hub

A free, accessible website of workshops for Leaders managing AI product development and Students beginning their technology journey.

Built with [MkDocs Material](https://squidfunk.github.io/mkdocs-material/) and published to GitHub Pages.

## 🌐 Live Site

[https://codess-aus.github.io/cuddly-fortnight/](https://codess-aus.github.io/cuddly-fortnight/)

## 📚 Workshop Tracks

### Leaders Track
For managers, executives, and team leads working with AI products.
- Workshop 1: Understanding AI
- Workshop 2: Managing AI Teams
- Workshop 3: AI Product Strategy
- Workshop 4: Ethics & Responsibility

### Students Track
For beginners new to technology and AI.
- Workshop 1: Intro to AI
- Workshop 2: GitHub Basics
- Workshop 3: Product Development
- Workshop 4: Build with AI

## 🛠 Local Development

```bash
pip install mkdocs-material
mkdocs serve
```

Then open [http://localhost:8000](http://localhost:8000).

## 🚀 Deployment

The site is automatically deployed to GitHub Pages on every push to `main` via GitHub Actions.
